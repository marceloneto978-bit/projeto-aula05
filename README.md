# projeto-aula05 

🍲 Site de Receitas Típicas

Este projeto consiste no desenvolvimento de um site de receitas típicas, criado utilizando HTML puro, sem o uso de CSS ou JavaScript.

O objetivo do projeto é apresentar diferentes receitas de forma simples, organizada e acessível, utilizando uma boa estrutura semântica em HTML.

📌 Sobre o projeto

O site reúne receitas típicas, apresentando informações como:

🥘 Nome da receita
🛒 Lista de ingredientes
👨‍🍳 Modo de preparo
📚 Informações adicionais

O projeto foi desenvolvido com foco no aprendizado e na aplicação dos principais conceitos de HTML5 e semântica web.

💻 Tecnologias utilizadas
HTML5
HTML semântico
Estrutura de páginas
Formulários
Links e navegação
Imagens e elementos multimídia

Não foram utilizados CSS, JavaScript ou frameworks.

🧱 Estrutura semântica

Durante o desenvolvimento foram utilizados elementos semânticos do HTML5, como:

<header> — cabeçalho da página
<nav> — área de navegação
<main> — conteúdo principal
<section> — organização das seções
<article> — conteúdo individual de cada receita
<aside> — informações complementares
<footer> — rodapé da página
🎯 Objetivo

O principal objetivo é praticar a construção de páginas web utilizando HTML puro, desenvolvendo uma estrutura organizada, semântica e de fácil compreensão.

Além disso, o projeto busca valorizar a culinária e as receitas típicas, apresentando seus ingredientes e formas de preparo de maneira simples.
